# Bomba-Tanquinho

# 🚿 Bomba para Tanquinho — Adaptação de Drenagem

Projeto de adaptação realizado em um **tanquinho de lavar roupas**, que originalmente utilizava apenas o **escoamento por gravidade** para retirar a água.

A modificação consiste na instalação de uma **bomba de drenagem reaproveitada de máquina de lavar roupas**, permitindo que a água seja retirada de forma **mais rápida e eficiente**, além de possibilitar maior flexibilidade na instalação da mangueira de saída.

## 💡 Sobre o projeto

O tanquinho originalmente possuía um sistema simples de drenagem por gravidade. Embora funcional, o processo de esvaziamento era relativamente lento e dependia da posição e da altura da mangueira de saída.

Para melhorar esse sistema, foi realizada uma adaptação utilizando uma **bomba de drenagem de máquina de lavar roupas**.

Com a instalação da bomba, o tanquinho passou a realizar a drenagem de maneira muito mais rápida.

### Antes da adaptação

💧 Drenagem por gravidade
🐌 Esvaziamento mais lento
📐 Dependência da posição da mangueira

### Depois da adaptação

⚡ Drenagem com bomba
🚀 Esvaziamento muito mais rápido
🔧 Sistema adaptado ao tanquinho
↗️ Maior flexibilidade para direcionar a água

## ⚙️ Funcionamento

O funcionamento do sistema é simples:

1. O tanquinho é utilizado normalmente durante a lavagem.
2. Ao finalizar o processo, a água é direcionada para a saída de drenagem.
3. A bomba de drenagem é acionada.
4. A bomba realiza a sucção da água do tanquinho.
5. A água é conduzida pela mangueira até o local de descarte.

```text
┌──────────────────┐
│     TANQUINHO    │
│                  │
│      💧💧💧      │
│       ÁGUA       │
└────────┬─────────┘
         │
         │ Entrada da bomba
         ▼
   ┌─────────────┐
   │    BOMBA    │
   │  DRENAGEM   │
   └──────┬──────┘
          │
          │ Água bombeada
          ▼
    ┌─────────────┐
    │   MANGUEIRA │
    │   DE SAÍDA  │
    └──────┬──────┘
           │
           ▼
       🚿 DESCARTE
```

## 🔧 Materiais utilizados

* 1 × Tanquinho de lavar roupas
* 1 × Bomba de drenagem de máquina de lavar roupas
* 1 × Mangueira para drenagem
* Conexões e adaptadores hidráulicos
* Abraçadeiras
* Fiação elétrica para alimentação da bomba
* Materiais de fixação
* Vedação para evitar vazamentos

> Os materiais podem variar de acordo com o modelo do tanquinho e da bomba utilizada.

## 🛠️ Adaptação

A adaptação foi realizada aproveitando a saída de água existente no tanquinho e instalando a bomba de drenagem no circuito de saída.

A bomba foi posicionada de maneira que a água pudesse ser direcionada para a mangueira de descarte, substituindo o funcionamento baseado exclusivamente na gravidade.

A montagem deve garantir que todas as conexões estejam bem vedadas e fixadas para evitar vazamentos durante o funcionamento.

## ⚡ Instalação elétrica

A bomba deve ser alimentada de acordo com a **tensão e especificações elétricas indicadas pelo fabricante**.

⚠️ **ATENÇÃO:** Este projeto envolve água e eletricidade. A instalação elétrica deve ser realizada com cuidado, mantendo conexões elétricas protegidas contra umidade e evitando qualquer possibilidade de contato entre água e partes energizadas.

Recomenda-se utilizar:

* Isolamento adequado das conexões;
* Caixa ou proteção para componentes elétricos;
* Aterramento quando aplicável;
* Dispositivo de proteção elétrica adequado;
* Instalação da bomba em local protegido contra respingos.

## 📈 Resultado

A principal melhoria obtida com a adaptação foi a **redução significativa do tempo necessário para esvaziar o tanquinho**.

A utilização da bomba de drenagem permite que a água seja retirada de maneira mais rápida do que no sistema original baseado apenas na gravidade.

O projeto também demonstra como componentes provenientes de outros equipamentos podem ser **reaproveitados para melhorar equipamentos existentes**, criando soluções simples e de baixo custo.
